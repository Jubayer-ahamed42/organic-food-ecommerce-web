- WoodMart-এর "কার্টে রাখুন" (`.add_to_cart_button`) বাটনে ক্লিক করলে তা সরাসরি লোকাল স্টোরেজে যুক্ত করে এবং হেডারের কার্ট কাউন্টার ও ড্রয়ার আপডেট করে।
- "অর্ডার করুন" (`.wd-buy-now-btn`) বাটনে ক্লিক করলে ১-ক্লিক ক্যাশ অন ডেলিভারি মোডাল ওপেন করে এবং সরাসরি WhatsApp-এ অর্ডার বার্তা পাঠায়।
- সার্চ বক্সে টাইপ করলে WoodMart সার্চ ড্রপডাউনে ইনস্ট্যান্ট রেজাল্ট প্রদর্শন করে।
